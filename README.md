# CollegeAppsProjects
Green Man Games are mini games that introduce me to basic platformer physics and they were created in middle school before AI.
1.) Normal Green Man: One of the first attempts at creating a platformer style game back in 7th/8th grade, learned ABAB collision 
2.) Green Man Jump: Gaining more experience 
3.) Green Man Platform: Exposure to momentum and handling ABAB collision
